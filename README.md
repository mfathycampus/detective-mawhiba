# 🔍 المحقق الرقمي — Detective Game

> مشروع Python النهائي | مؤسسة موهبة — برمجة الحاسب 2026

لعبة ويب تفاعلية مبنية بـ Flask تجمع 8 مفاهيم برمجية في قصة تحقيق مثيرة.

---

## 🎮 اللعبة

سُرقت قاعدة بيانات مشفرة من **مكتبة الأكواد**. مهمتك كمحقق:
- فك الشيفرة السرية
- البحث في قاعدة المشتبهين
- جمع الأدلة وتحليلها
- إصدار حكمك النهائي واكشف المجرم!

---

## 🧪 المفاهيم البرمجية

| المفهوم | كيف يظهر |
|---------|----------|
| شيفرة قيصر | فك تشفير الرسالة السرية |
| البحث الثنائي O(log n) | البحث في قاعدة المشتبهين |
| فرز المصفوفات | ترتيب الأدلة بالأهمية |
| OOP — Class & Objects | كلاس Suspect و Detective |
| مثلث باسكال | توليد مفتاح تشفير ثانٍ |
| الاستدعاء الذاتي | خوارزمية الحكم النهائي |
| قراءة/كتابة الملفات | حفظ تقرير التحقيق |
| try/except | حماية من أخطاء المدخلات |

## 🚀 تشغيل محلياً

```bash
git clone https://github.com/YOUR_USERNAME/detective-mawhiba
cd detective-mawhiba
pip install -r requirements.txt
python app.py
```

ثم افتح المتصفح على: `http://localhost:5000`

---

## ☁️ نشر مجاني على Render.com

1. ارفع المشروع على GitHub
2. اذهب إلى [render.com](https://render.com) وسجّل دخول بحساب GitHub
3. اضغط **New → Web Service**
4. اختر هذا الـ repository
5. Render يكتشف `render.yaml` تلقائياً — اضغط **Deploy**
6. بعد دقيقتين يظهر رابطك الحي! 🎉
